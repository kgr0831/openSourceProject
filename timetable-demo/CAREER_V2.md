# 진로 기반 과목 추천 V2

설명 수집·매칭·검증·오탈자 교정 과정은 [수집·검증 정리](../docs/course-description-collection.md)를 참고하세요. 과목별 검수 결과와 교정 이력은 `data/course_descriptions_typo_audit.csv`, `data/course_descriptions_full_typo_log.json`에 보관합니다.

최신 main `741ce4f`의 실제 2026년 강좌·학기·학과 선택 구조 위에 구현했다. 로컬 작업 브랜치: `feat_career_v2`.

## 사용 흐름

홈 → 희망진로 검색 → 전공·교양 추천 목록 → 내 시간표 만들기에서 **꼭 듣기** → OR-Tools 시간표 생성.

진로 추천에는 과목명·개설학과 기준 **2,195개 그룹**을 사용한다. 실제 시간표의 학기별 과목 그룹(2,383개) 및 분반 4,722행과 구분한다.

## 추천 방식

1. Codex가 희망 진로를 한국어·영어 과목 검색어로 확장한다. 직접 관련 주제뿐 아니라 기초 전공·관련 교양도 포함한다.
2. 전체 2,195개에서 과목명·학과·설명으로 후보를 검색한다. 과목명 일치를 가장 크게 반영하고, 설명 유무만으로 가산·감점하지 않는다.
3. 최대 80개 후보를 Codex가 평가하고, 관련성 높음·보통인 과목을 전공·교양 두 열에 표시한다. 화면에 전체 검색 수와 평가 후보 수를 보여 준다.

임베딩이나 외부 검색 API를 사용하지 않는 **검색어 확장 + 가중 문자열 검색 + LLM 평가** 구조다. 전체 과목이 검색 대상이지만 모든 과목을 LLM이 평가하지는 않는다. 검색어와 표기 차이, 후보 상한으로 인한 누락 가능성은 남는다.

| 근거 유형 | 과목 수 | 판단 기준 |
|---|---:|---|
| 해당 과목 설명 | 1,719 | 과목명 + 학과 + 공식 요람·웹 설명 또는 교양 요약 |
| 이전 과목 참고 설명 | 38 | 과목명 + 학과 중심, 공식 대응표로 연결한 설명은 보조 |
| 설명 없음 | 438 | 과목명 + 학과. 구체적인 수업 내용을 생성하지 않음 |

모호한 과목명은 판단을 보류한다. 이수 이력으로 과목을 제외하거나, 추천 목록 전체를 자동으로 필수·우선 과목에 넣지 않는다. AI에는 진로와 공개된 과목 정보만 보내며 개인 일정·성적·기록은 보내지 않는다. 기존 Codex 연결을 사용한다.

## 실제 강좌 연결

- 추천 목록은 `career-과목키`로 과목을 식별한다. 이름이 같아도 개설학과가 다르면 별도 과목이다.
- 필수 선택 시 현재 학기·학과에서 조회된 강좌 중 **과목명 + 개설학과 + 원본 과목번호**가 모두 맞는 분반이 있는 실제 시간표 과목 ID로 연결한다.
- 시간 미등록 등 사용할 수 없는 분반만 있는 과목은 필수 선택 목록에 넣지 않는다. 다른 학기에만 있는 과목도 진로 목록에는 남겨 두고 현재 연결 불가로 표시한다.
- 복수 ID 그룹에 서로 다른 실제 과목이 있으면 각각 선택한다. 사용자가 누른 실제 과목 ID만 기존 OR-Tools의 `required_course_ids`에 전달한다.
- 조회 가능은 수강 자격 보장이 아니다. 학과별 허용 여부·여석은 학교에서 확인한다.

## 데이터·검증

`data/course_descriptions.csv`는 별도 수집·교정한 2,195행 파일을 원본 그대로 복사했다. 4,722행 강좌 원본은 변경하지 않았다. 출처·연도·오탈자 검토사유를 유지하며, 2025년 설명을 2026년 강의계획서로 간주하지 않는다.

서버 시작 시 모든 설명 그룹이 실제 데이터에 연결되는지 검사한다. 저장 목록에는 설명 데이터 해시를 포함해, 데이터가 바뀌면 이전 추천을 다시 검색하도록 한다. 기존 V1 저장 형식과 캘린더 기능은 호환된다.

검증: 전체 그룹 연결·근거 유형 집계, 설명 없는 과목 검색, 학과/번호 불일치 연결 거부, 모델 응답 검증, 취소·빈 검색 결과, 실제 OR-Tools 필수 포함, 브라우저 저장·복원·실패 보존·출처·모바일. AI 응답은 테스트 대역으로 검증하며 실제 계정의 모델 응답 품질·소요시간은 별도로 확인해야 한다.

실행: `npm ci` → 처음 한 번 `npm run setup:solver` → `npm start`. 테스트: `npm test`, `npm run test:ui`, `npm run test:solver`.

이번 로컬 검증 결과: Node 테스트 83개, Python 엔진 테스트 20개 통과. 브라우저는 Chromium 12개 통과(기존 학과 선택 테스트의 화면 전환 대기 보완 후 해당 테스트 재확인), WebKit 선택 테스트 1개는 런타임 미설정으로 건너뛰었다. 데스크톱 1440px·모바일 390px에서 V2 화면도 확인했다. 실계정 AI 호출은 하지 않았다.
