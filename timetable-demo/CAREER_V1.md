# 진로 과목 탐색과 시간표 필수 선택 — V1

작업 브랜치: `feat_career`. 진로 탐색 목록과 시간표 필수 선택을 분리한 V1입니다.

## 사용 흐름

1. 홈에서 **내 시간표 만들기** 또는 **희망진로 검색** 중 시작 경로를 고릅니다. **진로 추천 과목 모아보기** 버튼은 저장된 목록으로 바로 이동합니다.
2. 희망진로 검색에서 진로를 입력하면 분석 성공 후 독립된 **추천 과목 탭**으로 이동합니다. **왼쪽 전공 / 오른쪽 교양** 두 열에 과목명·학점·관련성·추천 이유를 표시합니다. 검색 화면의 **저장된 진로 추천 과목 보기**, 사이드바·하단의 **추천 과목**으로도 이동합니다.
3. 목록은 기존 브라우저 저장소에 보관되며 새로고침해도 복원됩니다. 진로를 다시 분석하면 성공한 결과로 교체합니다. 실패하면 이전 목록을 유지합니다.
4. **이번 학기에 꼭 들을 과목 고르기**를 눌러 시간표 화면으로 이동합니다. 저장된 추천 목록을 다시 보여줍니다.
5. 원하는 과목의 **꼭 듣기**를 누릅니다. 선택한 과목만 `requiredCourseIds`에 추가하며 다시 누르면 해제됩니다. 일반 과목 선택 목록과 같은 상태를 공유합니다.
6. 생활 패턴에서 학점·요일·시간 등의 취향을 설정한 뒤 OR-Tools로 시간표를 생성합니다. 필수 과목끼리 충돌하거나 학점 조건을 충족하지 못하면 조건을 수정하도록 안내합니다.

**추천 목록 전체를 한 학기에 듣도록 강제하지 않습니다.** 진로 분석은 `requiredCourseIds`, `preferredCourseIds`, `excludedCourseIds`를 변경하지 않습니다. 목록에서 선택하지 않은 과목에는 자동 우선순위를 부여하지 않지만 일반 후보로는 선택될 수 있습니다. 학생이 직접 지정한 다른 관심·필수·제외 조건은 그대로 사용합니다.

## 기수강 기능 변경

이전 V1의 수강 이력 입력·학기별 완료 확인·기수강 자동 제외 흐름은 제거했습니다. 이미 저장된 `courseHistory` 데이터는 삭제하지 않지만 추천이나 저장의 제한 조건으로 읽지 않습니다. 예전 `completedCourseIds` 요청도 자동 제외 조건으로 처리하지 않습니다. 학생이 직접 선택한 일반 제외 과목 기능은 유지합니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `career.mjs` | `POST /api/career`: 진로 문장만 받고 전체 과목명을 평가, 시간표 요청과 독립된 추천 목록 반환 |
| `career-instructions.mjs` | 과목명 기반 평가 지침 |
| `public/career-model.mjs` | 저장 목록 검증, 전공·교양 그룹화, 명시적인 필수 선택 토글 |
| `public/planner.js` | `careerRecommendations` 저장·복원, 저장 실패 시 기존 데이터 보존 |
| `public/app.js` | 진로 추천 탭과 시간표의 필수 과목 선택 패널 |
| `schedule.mjs` | 사용자가 선택한 필수·제외·관심 조건을 기존 OR-Tools 계약으로 전달 |

AI에는 희망 진로·고정 학과명·과목 ID/과목명만 전달합니다. 일정·수강 기록·메모는 보내지 않습니다. 후보 외 ID·중복·누락·잘못된 관련성·빈 설명을 거절합니다. RAG·Web Search·벡터 DB는 사용하지 않습니다.

## 현재 데이터 범위

현재 팀 프로젝트의 AI소프트웨어학부 전공 32개·교양 18개를 사용합니다. 분반·시간·강의실은 가상입니다. 상위 폴더의 실제 CSV는 연결하지 않았으며 학과 선택·실제 개설 학기·수강 자격을 판정하지 않습니다. 과목명만으로 강의 내용·선수과목·졸업 요건을 추정하지 않습니다.

## 실행과 검증

```sh
cd timetable-demo
npm run setup:solver
npm start
npm test
```

`tests/career.test.mjs`는 추천과 시간표 조건의 독립성, 전공·교양 분류, 목록 저장·복원·저장 실패, 기수강 제외 제거, 필수 선택·해제와 실제 엔진 반영을 검사합니다. `tests/career-server.test.mjs`는 테스트 AI 응답으로 HTTP API를 실행하고 선택된 과목을 실제 OR-Tools에 전달합니다. 실제 AI 계정으로 과금 요청을 자동 실행하지 않습니다.
