# 교과목 설명 수집·검증 정리

> 목적: 과목명만 사용하던 진로 추천을 개선하기 위해, 학교 공식 자료의 교과목 설명을 연결했다. 기준일: 2026-11-18.

## 1. 대상과 수집 출처

2026년 시간표 **4,722강좌**를 **과목명 + 개설학과 기준 2,195개 그룹**으로 묶었다. 분반 중복을 줄이되, 같은 이름이라도 학과가 다르면 별도로 유지했다.

- **2025년 숭실대학교 대학요람:** 과목 개요와 과목번호 수집.
- **학과·베어드학부대학 공식 홈페이지:** 요람 누락 보완, 교양 소개 요약.
- **AI대학 공식 기존과목 대응표:** 개편된 과목과 이전 과목 연결. 이전 과목의 설명은 참고 설명으로 구분.

개별 분반의 강의계획서를 수집한 것은 아니다. 사용 가능한 2026년 중앙 요람 원문은 확보하지 못해, 2025년 요람과 공개된 학과 자료를 활용했다.

## 2. 추출·매칭 방법

**사용 기술:** Python 기반 수집·정제, HTML 파싱(BeautifulSoup), macOS Vision OCR, 문자열 정규화·유사도 비교, CSV 연결 및 해시 검증.

1. 공식 HTML과 요람의 공개 텍스트·표 이미지를 수집했다.
2. 이미지 표는 OCR로 읽고 과목번호·과목명·설명 열을 분리했다.
3. 원본 과목번호 앞 8자리로 후보를 찾은 뒤, **과목명과 학과·표 위치를 추가 대조**했다. 번호나 이름만으로 확정하지 않았다.
4. 각 설명에 출처 URL, 자료 연도, 요람 페이지, 매칭 방법과 검토사유를 기록했다.

## 3. 검증과 수정

| 단계 | 확인·조치 |
|---|---|
| 과목 대응 검사 | 번호·명칭 불일치, 복수 ID, 설명 잘림은 확정 보류 |
| 추출 오류 복구 | 설명 열을 분리해 재OCR하고 디지털 본문과 대조. 열 경계 오류와 누락 문장 복구 |
| 기존 검토안 반영 | 문장 누락 복원 197건, 표기 교정 94건, 교양 요약 보완 4건 반영 |
| 전체 오탈자 검사 | 설명 보유 **1,757개 전부**에 원문 자동 대조·형식·영어 용어 검사. 345과목 추가 직접 검토, 29과목 요람 이미지 확인 |
| 교정 결과 | 1차 14과목 16곳 수정 후, 전체 검사에서 추가로 **57과목 60항목** 수정 |

수정 예: `먹급수 → 멱급수`, `인공지능(AT) → 인공지능(AI)`, `2-변환 → Z-변환`. 깨진 한자, 설명에 섞인 `3/3` 학점 표기·표 세로선, 중복 문단과 괄호 누락도 정리했다. 재OCR 결과를 무조건 정답으로 채택하지 않았으며, 원문 자체의 오타를 교정한 경우도 근거를 남겼다.

**남은 확인사항:** 금융경제학과 `한국경제론`의 “경체 전공과목”은 원문도 불명확해 유지했다. 전체 검사는 모든 글자를 사람이 정독했다거나 무오류를 보증한다는 의미는 아니다.

## 4. 최종 데이터

| 설명 구분 | 과목 수 |
|---|---:|
| 2025년 요람 직접 대응 설명 | 1,601 |
| 공식 학과 웹 설명 | 94 |
| 공식 교양 소개 기반 요약 | 24 |
| 공식 대응표로 연결한 이전 과목 참고 설명 | 38 |
| **설명 확보 합계** | **1,757** |
| 미확보·대응 보류 | 438 |
| **전체** | **2,195** |

미확보·보류 438개는 설명 미확보 222개, 명칭 불일치 184개, 잘림 가능 27개, 복수 ID 5개다. 내용을 추정해서 채우지 않았다.

## 5. 저장과 V2 활용 원칙

- **원본 보존:** `timetable-demo/data/courses.csv`는 수정하지 않았다. 수정 전 설명 파일은 백업하고 교정 이력은 별도로 저장했다.
- **진로 추천:** `course_descriptions.csv` **2,195행** 사용. 설명이 있으면 과목명·학과·설명을 활용하고, 없으면 과목명·학과로 판단한다.
- **시간표 생성:** `courses_with_descriptions.csv` **4,722행** 사용. 추천 과목을 과목키·원본 과목번호 목록으로 연결한 뒤 선택 학기의 분반·시간을 조회한다.
- **근거 구분:** 이전 과목 참고 설명 38개를 현재 과목의 확정 설명으로 취급하지 않는다. 2025년 설명은 2026년 개별 수업 내용과 다를 수 있다.

원본 4,722행·20개 열의 값과 순서, 원본 파일 해시, 과목키와 두 설명 CSV의 연결 일치를 검증했다. 상세 결과는 `timetable-demo/data/course_descriptions_typo_audit.csv`, 교정 이력은 같은 폴더의 `course_descriptions_full_typo_log.json`에 있다.
