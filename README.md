# 숭실대 시간표 추천 데모

원하는 요일·시간·학점과 관심 분야를 입력하면 수업이 겹치지 않는 시간표를 최대 3개 추천합니다. AI 추천은 본인의 Codex 계정으로 실행합니다.

[서비스 제안서 — 실제 화면 중심 HTML](docs/시간표_추천_제안서.html)

HTML 파일 하나만 내려받아 열면 이미지가 포함된 6개 페이지로 확인할 수 있습니다. 좌우 화살표로 이동하고 화면 이미지를 클릭하면 확대됩니다.

## 실행

Windows에 **Google Chrome, Node.js 20 이상, Python 3.10 이상**이 필요합니다. AI 추천을 사용할 때만 Codex CLI와 계정 연결이 필요합니다.

1. 이 저장소를 내려받고 압축을 풉니다.
2. 처음 한 번 `timetable-demo` 폴더에서 `npm run setup:solver`를 실행합니다. 프로젝트 전용 Python 환경에 OR-Tools 9.15.6755를 설치합니다.
3. **시간표 데모 시작.bat**를 더블클릭합니다. 준비가 끝나면 크롬이 열립니다.
4. **내 시간표 만들기 → 과목 선택 → 생활 패턴** 순서로 조건을 정합니다.
5. **추천 시간표 보기**에서 추천안을 비교하고 학기 기간을 정해 저장합니다.

**터미널 창을 닫거나 Ctrl+C를 누르면 데모가 종료됩니다.** 추가 npm 패키지 설치는 필요하지 않습니다. **문장으로 요청하고 싶다면**을 선택하면 Codex 연결과 AI 추천을 사용할 수 있습니다.

모바일에서는 한 단계씩 조건을 설정하고, PC에서는 시간표와 추천안을 나란히 비교합니다. Figma의 차콜·블루 색상과 과목별 차분한 색을 적용했으며 그라데이션은 사용하지 않습니다.

## 요청 예시

- “수요일만 수업을 듣고, 전공 6학점과 교양 2학점으로 골라줘.”
- “전공 9학점, 교양 4학점으로 짜줘. 교양은 알아서 추천해줘.”
- “교양만 6학점 듣고 싶어. 독서와 글쓰기에 관심이 있어.”
- “월요일과 수요일에만 등교하고 총 12~14학점을 듣고 싶어.”

## 데이터와 범위

- **진로 기반 과목 탐색:** AI·컴퓨터비전, 데이터 분석, 웹·백엔드의 단계별 예시 과목을 추천 조건에 적용하고 이수 과목 제외
- **학기 캘린더:** 시간표를 학기 수업 일정으로 저장하고 휴강·시험·보강·개인 일정, 이번 일정/이후 반복 변경 및 시간 겹침 확인
- **수강 경험:** 가상 조언의 과목 조합 적용과 내 시간표 기록. 실제 선배 후기나 공개 게시판은 아님
- **추가 기능 — ICS 내보내기:** 변경을 반영한 학기 일정을 파일로 다운로드. 휴강·취소 제외, 자동 동기화 없음

일정과 내 기록은 현재 브라우저에만 저장됩니다. 브라우저 데이터를 지우거나 다른 주소·포트로 접속하면 기존 기록을 사용할 수 없습니다.

숭실대 AI소프트웨어학부 전공 32개와 교양 18개, 총 **50과목·150개 가상 분반**을 제공합니다. 과목명·학점은 공식 교육과정을 참고했으며, **수업 시간·분반·강의실은 데모용 가상 데이터**입니다. 실제 수강 신청이나 졸업 요건 판정에는 사용할 수 없습니다.

추천·분반 대체·최소 조건 완화는 실제 **OR-Tools CP-SAT**으로 계산합니다. 세부 설정에서 필수 등교일·오전 수업 상한·점심시간을 지정하고, 결과가 없을 때만 허용할 변경 범위를 직접 선택합니다. 바뀐 조건을 확인하고 저장하기 전까지 기존 시간표는 유지됩니다.

AI를 사용하면 요청을 조건으로 해석하고, 검증된 후보의 추천 이유를 설명합니다. 엔진 연결 계약과 검증 범위는 [OR-Tools 적용 안내](timetable-demo/CONTRACT.md), 실행 증거는 [검증 기록](timetable-demo/solver/VALIDATION.md)에 있습니다.

## 개발 및 검증

```powershell
cd timetable-demo
npm run setup:solver
npm start
npm test
npm run test:solver
```

로컬 주소는 `http://127.0.0.1:4317`입니다. 계정 인증 정보는 Codex가 관리하며 이 앱은 인증 파일을 읽거나 복사하지 않습니다.
