# 숭실대 시간표 추천 데모

원하는 요일·시간·학점과 관심 분야를 입력하면 수업이 겹치지 않는 시간표를 최대 3개 추천합니다. AI 추천은 본인의 Codex 계정으로 실행합니다.

[서비스 제안서 — 실제 화면 중심 HTML](docs/시간표_추천_제안서.html)

HTML 파일 하나만 내려받아 열면 이미지가 포함된 6개 페이지로 확인할 수 있습니다. 좌우 화살표로 이동하고 화면 이미지를 클릭하면 확대됩니다.

## 실행

Windows에 **Google Chrome, Node.js 20.18.1 이상, Python 3.10 이상**이 필요합니다. AI 추천에는 **Codex CLI**도 필요합니다.

1. 이 저장소를 내려받고 압축을 풉니다.
2. 처음 한 번 `timetable-demo` 폴더에서 `npm run setup:solver`를 실행합니다. 프로젝트 전용 Python 환경에 OR-Tools 9.15.6755를 설치합니다.
3. **시간표 데모 시작.bat**를 더블클릭합니다. 준비가 끝나면 크롬이 열립니다.
4. **내 시간표 만들기 → 과목 선택 → 생활 패턴** 순서로 조건을 정합니다.
5. **추천 시간표 보기**에서 추천안을 비교하고 학기 기간을 정해 저장합니다.

**터미널 창을 닫거나 Ctrl+C를 누르면 데모가 종료됩니다.** LMS 구성 요소는 첫 실행 때 자동으로 준비합니다. 기본 시간표 추천과 LMS 일정은 Codex 연결 없이 이용할 수 있습니다. AI 요청은 생활 패턴 화면의 **문장으로 요청하고 싶다면**에서 이용합니다.

## 내 LMS 일정을 캘린더에 반영하기

1. **학기 일정 → 내 LMS 일정 → 숭실대 LMS 연결**을 누릅니다.
2. 학교 창에서 직접 로그인합니다. 연결되면 학교 창은 닫히고 백그라운드로 동작합니다.
3. 가져올 과목만 체크하고 **선택한 과목 일정 가져오기**를 누릅니다.

시간표를 만들지 않아도 실제 과제·시험·강의 마감을 볼 수 있습니다. 다시 가져오면 같은 일정의 변경 내용을 갱신하고 중복을 만들지 않습니다. 일부 조회가 실패한 과목의 기존 일정은 보존합니다. 일정 클릭으로 LMS 원문을 확인하고, 기존 수업·개인 일정과 함께 ICS로 내보낼 수 있습니다.

학교 계정별로 일정을 분리해 이 브라우저에 저장합니다. 로그아웃하면 해당 계정의 일정을 숨기고, 같은 계정으로 다시 연결하면 복원합니다. 학교 로그인은 Windows 계정으로 암호화해 보관합니다. 별도 자료 보관 프로그램 ‘LMS 모아’와 로그인 보관함을 분리했으므로, 본 프로젝트에서 처음 한 번 학교 로그인이 필요합니다.

**일정 가져오기를 누를 때 갱신합니다.** 공지 본문에만 적힌 날짜·휴강은 직접 확인해야 하며, 외부 캘린더로 자동 전송하지 않습니다.

## 요청 예시

- “수요일만 수업을 듣고, 전공 6학점과 교양 2학점으로 골라줘.”
- “전공 9학점, 교양 4학점으로 짜줘. 교양은 알아서 추천해줘.”
- “교양만 6학점 듣고 싶어. 독서와 글쓰기에 관심이 있어.”
- “월요일과 수요일에만 등교하고 총 12~14학점을 듣고 싶어.”

## 데이터와 범위

- **진로 기반 과목 탐색:** AI·컴퓨터비전, 데이터 분석, 웹·백엔드의 단계별 예시 과목을 추천 조건에 적용하고 이수 과목 제외
- **학기 캘린더**에서 주간 시간표, 월간 달력, 선택한 하루의 목록을 볼 수 있습니다. 일정을 눌러 휴강·시험·보강·개인 일정을 확인하고 수정합니다. [학기 캘린더 사용법](timetable-demo/README.md#학기-캘린더-사용법)
- **LMS 연결:** 선택한 실제 수강 과목의 개인 마감·종일 일정 가져오기, 계정별 저장, 변경 반영 및 중복 방지
- **수강 경험:** 가상 조언의 과목 조합 적용과 내 시간표 기록. 실제 선배 후기나 공개 게시판은 아님
- **추가 기능 — ICS 내보내기:** 변경을 반영한 학기 일정을 파일로 다운로드. 휴강·취소 제외, 자동 동기화 없음

일정과 내 기록은 현재 브라우저에만 저장됩니다. 브라우저 데이터를 지우거나 다른 주소·포트로 접속하면 기존 기록을 사용할 수 없습니다.

숭실대 AI소프트웨어학부 전공 32개와 교양 18개, 총 **50과목·150개 가상 분반**을 제공합니다. 과목명·학점은 공식 교육과정을 참고했으며, **수업 시간·분반·강의실은 데모용 가상 데이터**입니다. 실제 수강 신청이나 졸업 요건 판정에는 사용할 수 없습니다.

추천·분반 대체·최소 조건 완화는 실제 **OR-Tools CP-SAT**으로 계산합니다. 세부 설정에서 필수 등교일·오전 수업 상한·점심시간을 지정하고, 결과가 없을 때만 허용할 변경 범위를 직접 선택합니다. 바뀐 조건을 확인하고 저장하기 전까지 기존 시간표는 유지됩니다.

AI를 사용하면 요청을 조건으로 해석하고, 검증된 후보의 추천 이유를 설명합니다. 엔진 연결 계약과 검증 범위는 [OR-Tools 적용 안내](timetable-demo/CONTRACT.md), 실행 증거는 [검증 기록](timetable-demo/solver/VALIDATION.md)에 있습니다.

## 별도 프로그램: LMS 모아

**`LMS 모아 시작.vbs`를 더블클릭**하세요. 실행이 막혀 있으면 `LMS 모아 시작.bat`를 사용하면 됩니다. 명령어 없이 화면에서 이용할 수 있습니다.

1. **숭실대 LMS 연결하기** → 새 학교 창에서 직접 로그인하고 강의실 열기
2. 내 과목에 체크 → **공지와 일정 / 강의자료까지 / 동영상까지** 선택
3. **저장하기** → 완료되면 **저장 폴더 열기**

로그인 후 학교 창은 자동으로 닫히고, 앱 창을 닫아도 저장은 백그라운드에서 계속됩니다. `LMS 모아 시작`을 다시 열면 진행 상황을 볼 수 있습니다. 로그인은 Windows 계정으로 암호화해 보관하고 다음 실행에 자동 복원합니다. 학교가 재인증을 요구하면 다시 로그인해야 합니다. **앱 종료**는 작업을 끝내고, **로그아웃**은 이 앱에 저장된 로그인을 지웁니다.

결과는 **내 다운로드 폴더 → LMS 모아**에 저장됩니다. 캘린더 파일과 AI 요약용 원문·요청 문구도 화면에서 받을 수 있습니다. Node.js 20.18.1 이상과 Chrome 또는 Edge가 필요하고, npm 구성 요소는 처음 실행할 때 자동으로 준비합니다.

Canvas API와 LearningX/Commons에서 본인의 공지·과제·일정·강의 자료를 수집합니다. 직접 다운로드 가능한 영상·자막을 지원하며 API 접근이 안 되는 목록은 로그인한 브라우저에서 보완합니다. AI 요약 실행과 캘린더 자동 동기화는 포함하지 않습니다. [사용법·지원 형식·개발자 안내](lms-parser/README.md)를 참고하세요.

`lms-parser/index.mjs`는 공통 파서 진입점입니다. `timetable-demo/lms-service.mjs`가 이를 직접 사용해 일정만 수집하고, `lms-parser/server.mjs`·`cli.mjs`는 독립 자료 보관 앱을 실행합니다. 본 프로젝트 사용 시 별도 LMS 모아 서버를 실행할 필요가 없습니다.

## 개발 및 검증

```powershell
cd timetable-demo
npm run setup:solver
npm start
npm test
npm run test:ui
```

로컬 주소는 `http://127.0.0.1:4317`입니다. AI 계정 인증은 Codex가 관리합니다. 학교 계정 인증은 공통 LMS 연결 모듈이 별도로 관리합니다. 파서 검증은 `lms-parser` 폴더에서 `npm test`, `npm run test:ui`로 실행합니다.
