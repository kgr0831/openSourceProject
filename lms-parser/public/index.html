    A LITTLE HELP

    처음이어도 괜찮아요.

    1. 1
      학교 계정을 연결해요

      ‘숭실대 LMS 연결하기’를 누르고, 새 창에서 로그인 후 강의실에 들어가세요. 연결되면 학교 창이 자동으로 닫혀요. 다음 실행에는 저장된 로그인으로 연결해요.

    2. 2
      과목과 저장할 내용을 골라요

      원하는 과목에 체크해 주세요. 영상이 필요 없다면 ‘강의자료까지’로 충분해요.

    3. 3
      저장하고, 폴더를 열어요

      저장이 끝나면 ‘저장 폴더 열기’를 누르세요. 자료는 파일 탐색기의 다운로드 → LMS 모아에 있어요.

    창을 닫아도 계속 저장해요

    앱 창을 닫고 다른 일을 해도 돼요. ‘LMS 모아 시작’을 다시 열면 진행 상황이 보여요. 완전히 끝내려면 ‘앱 종료’를 눌러 주세요. PC 종료·절전 중에는 작업이 계속되지 않아요.

    로그인은 이 PC의 Windows 계정으로 보호해 보관해요. ‘로그아웃’을 누르면 앱에 저장된 로그인을 지워요. 학교에서 로그인 유효 기간이 끝나면 다시 연결해 주세요.

    캘린더와 AI는 이렇게 사용해요

    ‘캘린더 파일 받기’로 받은 파일을 캘린더 앱에서 가져오세요. 자동 동기화는 아니에요.

    AI에 요약용 자료와 필요한 원본 문서를 첨부하고, ‘요약 요청 문구’를 복사해 보내세요. 자료를 모으는 동안 AI에 자동으로 전송하지 않아요.

    진행 중인 저장이 있어요.

    앱을 종료하면 저장을 중단해요.
    이미 저장된 파일은 그대로 남습니다.
